Rubik's Trainer

揃っています

キューブの面をスワイプするとその列が回ります。キューブの外側をドラッグ（PCは右ドラッグでどこでも）すると視点が回ります。

人差し指の J / F で U / U'、中指の I / K で R / R'、D / E で L / L'。

展開図

初心者向け：LBL法で6面を揃えよう

1段ずつ揃えていく、いちばん基本的な解き方です。各手順の「3Dで練習」を押すと、その手順で揃う状態が3Dキューブにセットされます。

回転記号の読み方
  • R / L / U / D / F / B：右・左・上・下・前・後ろの面を、その面を正面から見て時計回りに90°回す
  • '（ダッシュ）：反時計回り（例：R' ）
  • 2：180°回す（例：U2）
  • x / y / z：キューブ全体の持ち替え（それぞれ R / U / F と同じ方向）
